## project details:

Game -> contains the Game class, which controls the main game cycle, with the main functions.
Class -> contains the various class used in the game, such as Character, Box, Platform...etc...
Home -> contains the Home class, comprensive of the shop and some other functions.
Main_game -> contains the game cycle (Game - Home ...), not the method itself as in Game, it's like the 'main' function. And the conditions to stop the game.

This is a simple platformer which main goal is to reach the highest possible score, obtaining coins and power ups along the way. The experience is based on "energy", once finished the game ends and you get teleported in the home, once here you get to buy upgrades, regarding three categories: energy, speed and jump. And now you can restart the game scoring an higher score time by time.
